- 📖 3D Velvet Book Opening with Sanskrit Invocations
- 📜 Pull-to-Reveal Save the Date Scroll with Live Countdown Clock
- 🌺 Festivities Carousel with 3D Card Depth (Lakhdav to Baraat & Pheras)

- 🗺 Interactive Navigation for Residence, Baraat, and Grand Reception

- 🌸 Falling Rose Petal Particles
